# Proyectos como carpetas

Solicitud: retirar tareas, plan, pruebas/evidencias y exportación. Mantener almacenamiento local sin Microsoft. El informe aporta la estructura documental; prevalecen las modificaciones explícitas del usuario.

1. Conservar registros anteriores y añadir propietario, integrantes y permisos lector/editor efectivos.
2. Crear carpetas de proyecto para cualquier cuenta activa y gestionar accesos por propietario/administrador.
3. Reemplazar paneles por proyectos con búsqueda, cuadrícula/lista, creación y archivo.
4. Retirar tareas/trabajos de la navegación y centrar el dashboard en archivos, proyectos, usuarios y actividad.
5. QR con IP local, sesión obligatoria, permisos vigentes, caducidad y revocación.
6. Verificar con pruebas aisladas, navegador, next lint y next build.
